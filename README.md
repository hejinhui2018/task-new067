# 直播导播流程单（Rundown Console）

面向直播导播团队的节目流程单。临时延长采访、插入内容时，立即看到后续环节如何变化；
固定开播点绝不被悄悄越过——超时先由缓冲段和可压缩环节消化，消化不下就明确报出冲突。

技术栈：React 18 + TypeScript + Vite，无后端，数据保存在浏览器 localStorage。

## 运行方式

要求 Node.js ≥ 18。

```bash
npm install        # 安装依赖
npm run dev        # 开发预览（默认 http://localhost:5173）
npm test           # 运行调度引擎与撤销/重做测试（vitest）
npm run build      # 类型检查（tsc --noEmit）+ 生产构建（输出 dist/）
npm run preview    # 预览生产构建
```

## 内置节目单（10:00 开播，30 分钟播出窗口）

| # | 环节 | 类型 | 计划时长 | 说明 |
|---|------|------|---------|------|
| 1 | 开场 | 常规 | 2:00 | 整体顺延 |
| 2 | 新闻 | 可压缩 | 5:00 | 最短可压至 3:00 |
| 3 | 采访 | 可压缩 | 6:00 | 最短可压至 4:00 |
| 4 | 缓冲 | 缓冲 | 2:00 | 可消耗至 0 |
| 5 | 连线 | **固定** | 5:00 | ⚓ 固定 10:15 开播 |
| 6 | 评论 | 常规 | 8:00 | 整体顺延 |
| 7 | 片尾 | 常规 | 2:00 | 10:30 准点收尾 |

## 调度规则

1. **整体顺延**：普通调整（改时长、拖动排序、插入/删除）后，每个环节紧跟前一环节。
2. **固定点保护**：固定环节之前的超时，按顺序消化——
   先扣「上一个固定点（或开播）到本固定点之间」的**缓冲段**，
   再按流程顺序压缩**可压缩环节**（压到各自下限为止）。
   消化只发生在同一区段内，不会跨固定点倒灌。
3. **冲突上报**：消化能力耗尽仍放不下 → 红色冲突横幅，标明超时量、已消化量、
   仍超出量与涉及环节。固定点仍在原时刻开播，系统绝不悄悄后移。
4. **空档**：固定点前内容不足时留出空档行（可点击 ＋ 插入内容），固定点依然准点。

计划时长是唯一的源数据；压缩量、开始/结束时间、冲突全部由引擎实时推导，
因此撤销/重做只需还原计划，时间与冲突会一起恢复。

## 演示：采访延长 4 分钟

1. 点击「采访」行的时长 `6:00`，输入 `10`（或 `10:00`）回车；
2. 琥珀色横幅显示：已自动消化超时 4:00 —— 缓冲 `2:00 → 0:00`、新闻 `5:00 → 3:00`；
3. 连线仍 ⚓ 10:15 准点开播，片尾仍 10:30 准点收尾，总时长 30:00 不变；
4. 表格中缓冲行显示「已耗尽」，新闻行显示 `5:00 → 3:00`；
5. `↶ 撤销`（Ctrl/⌘+Z）后缓冲、新闻、冲突提示全部还原，`↷ 重做` 再次生效。

制造一次冲突：把「开场」延长 7 分钟以上（消化能力 = 缓冲 2:00 + 新闻 2:00 + 采访 2:00），
或将连线的固定时间改早到消化能力不够的位置，即可看到红色冲突横幅。

## 界面与操作

- **顶栏**：当前总时长（含与窗口的偏差）、收尾时刻、缓冲余量、可消化余量、固定点数、冲突数；
  撤销/重做/重置；播放头预演（1×/10×/60×/240× 倍速）。
- **时间轴**：各环节按比例成色块，⚓ 固定点、斜纹空档、红色冲突区、窗口刻度线一目了然；
  点击时间轴可定位播放头。
- **流程单表格**：拖动 ⠿ 排序；点击时长修改（支持 `6:00` 或 `6` 分钟）；双击标题改名；
  📌 把当前开始时间设为固定开播点；行内 ＋ 插入、🗑 删除（均可撤销）。
- **快捷键**：空格 播放/暂停 · Ctrl/⌘+Z 撤销 · Ctrl/⌘+Shift+Z（或 Ctrl+Y）重做。
- 所有修改自动保存到浏览器 localStorage（含撤销栈），刷新后原样恢复。

## 测试

`npm test` 覆盖：

- `src/engine/schedule.test.ts` — 时间传播（整体顺延）、缓冲→压缩的消化顺序与明细、
  压缩下限、固定点冲突（量与涉及环节）、空档、多固定点分区消化、余量统计；
- `src/store/reducer.test.ts` — 撤销/重做后时间与冲突一起恢复、重做栈清空、
  拖动排序、设为固定点不扰动流程、时长下限钳制、插入/删除；
- `src/engine/time.test.ts` — 时间格式化与解析。

## 目录结构

```
src/
  engine/schedule.ts    调度引擎（纯函数）：顺延、消化、冲突、空档
  engine/time.ts        时间格式化与解析
  store/reducer.ts      快照式撤销/重做 + 全部修改动作
  store/defaultShow.ts  内置 30 分钟节目单
  store/persistence.ts  localStorage 读写
  hooks/usePlayhead.ts  播放头（倍速预演）
  components/           顶栏、时间轴、告警横幅、流程单表格、环节行
```
